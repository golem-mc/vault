# Vault for golem

An unofficial port of [Vault](https://github.com/MilkBowl/Vault) to
[golem](https://github.com/golem-mc/golem), the Minecraft: Java Edition server written in Go:
the shared economy, permission and chat API that plugins provide and use, so a plugin that
charges money works with whichever economy plugin a server runs.

Work in progress.
